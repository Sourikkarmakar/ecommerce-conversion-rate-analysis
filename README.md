E-commerce Conversion Rate Analytics

📊 Project Overview

This project analyzes e-commerce data to understand customer conversion rates, visitor behavior, and revenue performance across different product categories.

The project was created using Microsoft Power BI to transform the data into interactive dashboards and visualizations.

🎯 Objectives

- Analyze the overall e-commerce conversion rate
- Compare conversion rates across product categories
- Analyze total revenue generated by each category
- Identify patterns in customer behavior
- Present insights through an interactive Power BI dashboard

🛠️ Tools Used

- Microsoft Power BI
- Data visualization
- Data analysis

📈 Dashboard

The Power BI dashboard includes:

- Total Visitors
- Total Revenue
- Conversion Rate
- Conversion Rate by Category
- Revenue by Category
- Interactive visualizations
